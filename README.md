# uinaf/react-json-logic

Build and evaluate [JsonLogic](http://jsonlogic.com) rules with headless React components.

```bash
pnpm add react-json-logic react react-dom
```

Requires React 19. Props, the `rule` factory, `validate()`, and the `data-rjl-*` styling hooks: [package README](packages/react-json-logic/README.md).
